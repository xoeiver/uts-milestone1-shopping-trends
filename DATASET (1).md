# Dokumentasi Sumber Dataset

- **Nama:** Customer Shopping Trends Dataset
- **Pembuat:** Sourav Banerjee
- **Sumber:** https://www.kaggle.com/datasets/iamsouravbanerjee/customer-shopping-trends-dataset
- **Lisensi / ketentuan penggunaan:** Other (specified in description). Dataset merupakan data sintetis (synthetic dataset). Ketentuan penggunaan perlu dikonfirmasi melalui deskripsi dataset atau pemiliknya.
- **Tanggal akses:** 5 November 2026
- **File yang digunakan:** `shopping_trends_updated.csv`
  - **Alasan memilih:** Menggunakan versi updated karena merupakan versi data yang diperbarui dan dipilih sebagai sumber data penelitian.
- **Ukuran:** 3.900 baris × 18 kolom
- **Unit observasi:** Satu baris merepresentasikan satu pelanggan beserta informasi karakteristik dan perilaku belanjanya.
- **Target:** `Subscription Status` (Yes/No)

## Cara memperoleh data
1. Buka link Kaggle di atas (perlu login), klik **Download**, lalu ekstrak.
2. Pilih file `shopping_trends_updated.csv`.
3. Letakkan satu file CSV di folder `data/` pada repository ini.

Dataset tidak diunggah ulang ke repository ini kecuali ketentuan lisensinya mengizinkan; gunakan petunjuk di atas untuk memperoleh dataset dari sumber aslinya.
